## LecoTrip

### 프로젝트 소개 🌏🛫

사용자가 제공하는 간단한 정보들을 통해 여행 일정을 추천하고 여행 일정을 수정 할 수 있도록 하여 편리하게 여행 계획을 구성 할 수 있도록 도와주는 플랫폼입니다.
여행가유는 사용자가 여행 계획에 소요되는 시간을 줄이고, 직관적이고 종합적인 여행 준비를 지원하는 것을 목표로 합니다.
이 플랫폼을 통해 사용자는 여행지와 여행 일정을 추천받고 여행 일정을 추가/수정하여 자신에게 맞는 여행일정을 간편하게 이용할 수 있습니다.

### 주요기능
- 여행 추천 기능
  
  LecoTrip은 사용자로부터 간단한 정보(여행 인원, 여행 예산, 여행 목적 등)를 통해 맞춤 여행지를 추천해주고 
  해당 여행지에 있는 관광지와 음식점을 추천해 드립니다. 
  여행 추천기능에는 두가지가 있으며 여행지 추천과 여행 조건 추천이 있습니다.
  여행지 추천은 가고싶은 여행지가 있는 경우 해당 여행지에 있는 관광지와 음식점을 추천해주고
  여행 조건 추천은 가고싶은 여행지가 없는 경우 여러 국가와 도시에 해당하는 예시를 먼저 사용자에게 보여주고 선택한 나라/도시에 따라 관광지와 음식점을 추천해주는 기능이 있습니다.
  <br/><br/><br/>

- 처방전 검색 기능
  
  1년이내 사용자가 처방받은 내역을 보여주는 기능입니다. 진료받은 병원, 처방전, 의약품목록 등을 확인 할 수 있습니다.
  <br/><br/><br/>

- 여행 정보 저장 및 수정
  
  여행지 검색이나 조건 검색을 통해 추천받은 일정을 스크랩하여 저장할 수 있고 저장된 일정을 수정 할 수 있는 기능입니다.
  <br/><br/><br/><br/>
